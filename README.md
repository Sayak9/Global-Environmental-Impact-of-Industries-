# Environmental Impact of Industries Dashboard

![Dashboard Preview](dashboard.png)

# Project Overview
This project explores global industrial sustainability metrics through an interactive Tableau dashboard. The goal was to transform raw environmental data into clear insights that business leaders and policymakers can use to track emissions, energy consumption, and recycling efficiency across multiple sectors and regions.

# Key Insights and Features
* Total energy usage stands at 37.5 million units while total water consumption reaches 49.9 million units.
* Carbon emissions total 16.2 million units alongside a solid average recycling rate of 72.02 percent globally.
* The time series analysis highlights a noticeable peak in energy consumption during 2022 before stabilizing in subsequent years.
* Regional breakdowns show varying environmental pressures across Asia, North America, Europe, Africa, Australia, South America, and the Middle East.
* Interactive filters allow users to slice data by specific industries, geographic regions, compliance levels, and product types to uncover hidden patterns.
* Detailed heatmaps map out recycling performance across different sectors and territories to identify top performers and areas needing improvement.

# Files Included
* Industrial Environmental Impact Dashboard.twbx containing all data sources, calculated fields, and fully formatted worksheets.
* dashboard.png displaying the live dashboard layout and visual hierarchy.

# How to Explore
1. Download the packaged workbook file from this repository.
2. Open the file using Tableau Desktop or Tableau Reader to interact with the filters and explore the underlying data visualizations.
3. Alternatively you can view the published version on Tableau Public if available.
